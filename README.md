# Воспроизводимый вычислительный конвейер предварительной диагностики рациональных эллиптических кривых

Репозиторий реализует воспроизводимый конвейер для целочисленных коротких моделей Вейерштрасса `y^2 = x^3 + ax + b` над `Q`. Stage A — целочисленный диагностический классификатор A1–A6. Stage B — точный вызов SageMath `torsion_subgroup()` на стратифицированной референсной выборке.

## Связь со статьёй и плакатом

Научная публикация: Н. А. Чистяков, Р. С. Адамова, «Вычислительная методика быстрой проверки наличия точек 3-го порядка на рациональных эллиптических кривых», «Вестник Воронежского государственного университета. Серия: Физика. Математика», 2026, № 1, с. 59–67. Эта статья является методической основой работы; текущие параметры запусков и численные результаты относятся к текущему снимку репозитория.

Докладчик по плакату — только Н. А. Чистяков. Р. С. Адамова указана как соавтор публикации и научной основы, а не как докладчик плаката.

## Среда и проверка

Зафиксированная среда результатов: SageMath 10.8, Sage Python 3.13.7, CMake 4.2.3, C++17 и Apple clang 21.0.0. Для сборки текущего C++-кода нужен Clang или GCC: реализация использует `__int128`.

```bash
conda env create -f environment.yml
conda activate rational-elliptic-diagnostics
python -m pip install -e .
python -m pytest -q
sage -python -m compileall -q src scripts tests
```

## Воспроизведение

Полная последовательность Stage A → Stage B → проверка → бенчмарк запускается из корня репозитория:

```bash
python scripts/run_stage_a.py --config configs/conference.yml --output-dir output
sage -python scripts/run_sage_reference.py --config configs/conference.yml --input output/stage_a_rows.csv --output-dir output
python scripts/verify_results.py --config configs/conference.yml --input-dir output --results-dir results
sage -python scripts/run_benchmark.py --config configs/conference.yml --sizes 10000 30000 100000 300000 --sample-per-size 1000 --repeats 3 --output-dir results
```

Stage A и верификатор поддерживают обычный `python`; бенчмарк также можно запустить через `python scripts/run_benchmark.py` при наличии `sage` в `PATH`.

Сквозное сравнение трёх сценариев, показанное на плакате, запускается отдельно:

```bash
sage -python scripts/run_workflow_benchmark.py --config configs/conference.yml --n 200000 --k 2000 --repeats 5 --output-dir results
```

Сценарий SageMath вычисляет точную группу для всех 200 000 пар коэффициентов. Python- и C++-гибриды диагностируют весь набор и вычисляют точные группы SageMath для общей стратифицированной подвыборки из 2 000 примеров. Их точное покрытие равно 1% против 100% у полного сценария. При этом одинаковый выход двух гибридных сценариев позволяет сопоставить их медианное полное время: 50,33 с для Python и 2,464 с для C++, отношение — 20,4.

| Файл | Содержание |
|---|---|
| `results/stage_a_summary.csv` | Численности и доли классов A1–A6 в Stage A. |
| `results/stage_b_reference.csv` | Точные порядки, инварианты и генераторы кручения для референсной выборки. |
| `results/calibration.csv` | Метрики на сбалансированной калибровке и эквивалентность Python/C++. |
| `results/benchmark_scaling.csv` | Медианные wall/CPU-времена и счётчики проверок для четырёх диапазонов. |
| `results/workflow_benchmark_runs.csv` | Пять запусков каждого из трёх сквозных сценариев с одинаковыми входом и контрольной подвыборкой. |
| `results/workflow_benchmark_summary.csv` | Медианы, квартильные границы и точное покрытие трёх сценариев. |
| `results/environment.json` | Обезличенная конфигурация машины и версии инструментов. |

## Методика измерений и лицензии

Stage A вычисляет диагностические признаки для 200 000 пар коэффициентов. Stage B вычисляет точные группы для стратифицированной подвыборки из 2 000 примеров. Калибровочный набор содержит 300 положительных и 300 отрицательных примеров (`300+300`). Измеренные времена зависят от машины и методики запуска.
